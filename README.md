# Signal Desk

Family dashboard for Oakville, Ontario: weather and what to wear, Environment Canada warnings,
GO Lakeshore West schedule, markets, and headlines for Oakville, Ontario, Canada, Egypt, the Gulf,
the USA and the world. It refreshes itself about every 15 minutes.

- Add or change topics and search words in `config.json`.
- Change the morning briefing time in `config.json` → `alerts.morning_briefing`.
- Phone alerts: install the free ntfy app and subscribe to the topic in `config.json` → `alerts.ntfy_topic`.
